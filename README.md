# VEXORA — Juego web

Sitio independiente de VEXORA para jugar desde el navegador.

Versión: 0.0.4  
Creador: vdavidc

Incluye dos niveles, el jefe Titán del Eclipse, minijuegos de cristales y drones, TOPS y chat beta. El juego y los minijuegos funcionan sin conexión. Para compartir chat y TOPS entre jugadores, publica el Worker de `cloudflare/` y configura su URL en el menú. Las instrucciones de publicación están en `cloudflare/README.md`.
